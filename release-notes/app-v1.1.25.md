## 변경 사항

- 앱과 PC 모두 File Manager를 앱 데이터 삭제 대상에서 제외해 매장 SMB 연결·인증 정보와 앱 설정을 보존합니다. 내부 공유 저장소의 사진·다운로드 파일 정리는 기존대로 진행합니다.
- 앱의 설치 버전 확인을 전체 패키지 정보 대신 패키지명·versionCode만 조회하는 방식으로 변경했습니다. 설치 정보가 출력 한도를 넘어 잘리면서 정상 설치된 File Manager를 실패로 표시하던 문제를 수정했습니다.
- 정확한 패키지명과 최소 버전을 검증하고, 조회 실패·잘린 결과·버전 누락은 계속 실패로 처리합니다. 필수 앱은 없거나 번들보다 구버전일 때만 데이터를 유지하는 덮어쓰기 설치를 진행합니다.
- Windows EXE에 같은 SMB 설정 보존 로직과 초기화 앱 1.1.25를 포함합니다.

## 검증

- PC 회귀 테스트 69개, Android 단위 테스트 70개, Android lint·APK 빌드와 병렬 시뮬레이션 8개 항목을 통과했습니다.
- 연결된 S23 Ultra의 File Manager 3.6.0(versionCode 2103060)이 번들 3.5.4보다 최신임을 확인했습니다. 기존 전체 패키지 조회는 약 66KB로 앱의 64KB 출력 한도를 넘었으며, 짧은 버전 조회는 정상 동작했습니다.
- 기기에서 필수 앱 설치·버전 확인 단계만 재실행하고 최종 검증까지 완료했습니다. 실패 0개 및 File Manager 데이터 디렉터리 유지를 확인했으며, 전체 초기화나 SMB 데이터 삭제는 실행하지 않았습니다.
