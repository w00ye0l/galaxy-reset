### 네이버 계정과 지도 로그인 세션 초기화

- 휴대폰 앱과 Windows EXE 모두 네이버 시스템 계정·인증 정보를 기기에서 제거합니다. 서비스 계정 탈퇴가 아닙니다.
- 시스템 계정이 이미 없어도 네이버 지도 앱 데이터를 초기화합니다. 기기 계정 제거 후에도 남을 수 있던 지도 내부 로그인 세션을 함께 정리합니다.
- 계정 목록 조회 실패·네이버 계정 잔존·지도 데이터 초기화 실패는 완료로 처리하지 않습니다. PC는 전체 단계 종료 후에도 계정 목록을 다시 검사합니다.
- 삼성 계정은 유지합니다. 자동 계정 제거 중에는 기기 화면을 켜고 잠금을 풀어 두세요.
- Windows EXE의 도움말·출력 경로도 UTF-8로 처리해 비한글 Windows의 실행 오류를 수정했습니다.

검증: S26에서 PC의 계정 단계만 실행한 뒤 시스템 네이버 계정 부재·삼성 계정 유지와, 지도 재실행 시 ‘NAVER 로그인(선택)’ 화면을 확인했습니다. Android 테스트 40개·lint·APK 빌드, PC 테스트 42개와 20대 병렬 시뮬레이션 8개 항목을 통과했습니다. 다른 초기화 단계는 이번 실기기 검사에서 재실행하지 않았습니다.

기존 EXE는 자동 업데이트되지 않습니다. PC에서 초기화하려면 이 릴리스의 새 Windows ZIP을 내려받아 사용하세요. 새 EXE에는 Android 1.1.17이 동봉됩니다. 기기에 설치된 앱은 ‘업데이트 확인’으로도 업데이트할 수 있습니다.
