## 변경 사항

- 앱·PC의 내부 저장소 초기화 결과를 실제 잔여 파일 조회로 판정합니다. 삭제 명령의 일시적인 경고가 남아 파일이 없는데도 실패로 표시될 수 있는 경로를 보완했습니다.
- 잔여 파일이 있으면 해당 단계에서 1회 자동 재시도합니다. 조회 실패·삭제 시간 초과·재시도 후 남은 파일은 계속 실패 또는 수동 확인으로 표시합니다.
- Shizuku 서버가 자동 시작된 뒤 초기화 앱의 권한 연결이 지연되는 경우, 앱을 직접 나갔다 들어오지 않아도 연결을 다시 요청하도록 보완했습니다. 초기화는 사용자가 버튼으로 실행해야 합니다.
- Windows EXE에도 같은 저장소 보완과 초기화 앱 1.1.24를 포함합니다.

## 검증

- PC 회귀 테스트 67개, Android 단위 테스트 65개, Android lint·APK 빌드 및 병렬 시뮬레이션 8개 항목을 통과했습니다.
- S26 Ultra(Android 17)에서 수정본 전체 19단계 완료, 내부 저장소 잔여 파일 0개 및 테스트 파일 삭제, 삼성 계정 1개 보존·비삼성 계정 0개, 완료 알림 0개를 확인했습니다.
- Shizuku를 종료한 상태에서 앱만 실행해 약 7초에 권한 연결과 초기화 버튼 활성화를 확인했습니다. USB가 연결된 상태에서 앱 자체 무선 ADB 경로를 검증했으며, 재부팅 후 테스트는 포함하지 않습니다.
- 기존의 간헐적인 저장소 실패 증상은 해당 S26에서 재현되지 않았습니다. 일시적 삭제 경고·재시도 성공·실제 잔여 파일·조회 실패·시간 초과는 회귀 테스트로 검증했습니다.
