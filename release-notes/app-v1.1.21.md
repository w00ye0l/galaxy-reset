### 업데이트 조회의 GitHub REST API 의존 제거

- 업데이트 확인 시 GitHub REST API 대신 최신 정식 릴리스의 `galaxy-reset-update.json`을 직접 읽습니다. 익명 REST API의 공인 IP별 시간당 조회 한도를 공유하던 경로를 제거했습니다.
- APK 주소는 업데이트 파일에 적힌 버전의 `app-v<버전>` 태그로 고정합니다. 확인 도중 최신 릴리스가 바뀌어도 다른 버전의 APK를 내려받지 않습니다.
- HTTPS와 다운로드 호스트 제한, 메타데이터 검사, APK 크기·SHA-256·패키지·버전·기존 서명 검증은 유지합니다.
- 기존 앱에서 조회 제한이 계속되면 이 릴리스의 APK를 직접 내려받아 업데이트하거나 새 PC EXE로 설치하세요. 앱을 삭제하거나 앱 데이터를 지울 필요는 없습니다.

실제 공개 최신 메타데이터의 직접 다운로드와 Galaxy S25의 앱 내 업데이트 확인 성공을 검증했습니다. Android 단위 테스트 54개, lint 및 APK 빌드가 통과했습니다. 이 검증에서는 초기화를 실행하지 않았습니다.
