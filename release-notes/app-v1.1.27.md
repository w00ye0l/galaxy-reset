## 변경 사항

- 삼성 앱 서랍의 여러 페이지에서 LOCARORA와 Language를 찾습니다. 바로가기가 다른 홈 페이지에 생성되면 실제 위치를 다시 확인한 뒤 메인 홈으로 옮깁니다.
- 홈 페이지 표시점이 숨겨져 있거나 사라진 기기에서도 삼성 런처의 페이지 구조를 읽어 현재 위치와 남은 페이지를 확인합니다.
- 갤러리, Play 스토어, LOCARORA, Language를 메인 홈 맨 아래 줄에 순서대로 배치합니다. 추가 홈 페이지를 제거하고 메인 홈 한 페이지만 남았는지 확인합니다.
- PC 초기화 프로그램에도 같은 홈 배치 로직이 담긴 1.1.27 APK를 동봉합니다.

## 실기기 검증

- S24에서 앱 서랍 두 번째 페이지에 있는 앱 탐색과 홈 배치를 확인했습니다. 마지막 단계만 재실행해 19/19단계 완료와 메인 홈 1/1페이지를 확인했습니다.
- S26에서 두 번째 홈 페이지의 바로가기를 메인 홈으로 옮기고, 추가 페이지를 제거한 뒤 기존 독과 설치 앱이 유지되는지 확인했습니다.
