## 변경 사항

- 불필요 앱 삭제 후 남은 비삼성 계정을 처리하도록 초기화 순서를 개선했습니다. 개별 실패가 발생해도 나머지 정리를 진행하고 최종 잔존 상태를 검증합니다.
- 유지하는 앱의 데이터 삭제 중복과 Galaxy Store·Samsung Cloud 복원 큐 정리 단계를 제거했습니다. 초기화 앱과 Shizuku 인증 정보는 보존합니다.
- 파일 관리자를 포함한 필수 앱은 없거나 번들보다 구버전일 때만 설치합니다. 더 최신 버전은 유지하며 파일 관리자 활성화 실패는 주의로 표시합니다.
- PC 무선 준비 결과를 초기화와 분리했습니다. 화면 하단 메뉴 오인, 비활성 페어링 메뉴, 기존 설정 화면 재사용을 처리하고 유효한 기존 인증은 재페어링 없이 사용합니다.
- 화면 꺼짐 시간을 먼저 10분으로 설정하고 완료·실패·중단 후 초기화 앱의 진행 알림을 제거합니다.
- 실제 명령 오류가 시간 초과로 잘못 표시되는 문제를 수정했습니다. 순서가 바뀐 이전 실행 기록은 이어 실행하지 않으며 앱 복구 기록은 보존합니다.

## 검증

- PC 회귀 테스트 63개, Android 단위 테스트 60개, Android lint·APK 빌드, 병렬 시뮬레이션 8개 항목을 통과했습니다.
- S25 Ultra(Android 17)의 정리 후 재실행에서 PC 약 55초, 앱 약 62초에 완료했습니다. 삼성 계정 유지, 비삼성 계정 0개, 완료 알림 0개 및 기존 ADB 인증 연결을 확인했습니다.
- 소요 시간은 기기의 데이터·설치 상태에 따라 달라집니다. S26 실기기 검증 결과를 포함하지 않습니다.
