### 네이버 계정 초기화 수정

- 앱 데이터 삭제만으로 남던 네이버 계정·인증 정보를 기기에서 제거합니다. 네이버 계정 탈퇴가 아닙니다.
- 계정 단계에서 백그라운드 제거가 안 되면 삼성 설정의 NAVER 계정 제거 절차를 자동 진행합니다.
- 실제 계정 목록에서 제거됐을 때만 완료 처리합니다. 제거 거부·잠금·화면 확인 실패·다른 비삼성 계정 잔존은 계속 표시합니다.
- 삼성 계정 보존과 다른 18단계는 유지합니다. 실행 중 화면을 켜고 잠금을 풀어 두세요.

이번 릴리스는 Android APK와 자체 업데이트 정보만 게시합니다. 기존 Windows EXE는 재빌드하지 않았으며, 그 EXE의 초기화 로직과 동봉 APK는 변경되지 않습니다. 기존 EXE로 준비한 기기에서도 초기화 앱을 1.1.16으로 업데이트한 뒤 **휴대폰 앱에서 초기화**하면 수정이 적용됩니다.

검증: 연결된 S26에서 네이버 지도 재로그인 후 계정 단계만 실행하여 네이버 계정 제거·삼성 계정 보존·계정 단계 완료 표시를 확인했습니다. 지도 재실행 후에도 네이버 계정이 다시 생기지 않았습니다. Android 단위 테스트 38개·lint·APK 빌드를 통과했습니다. 다른 초기화 단계는 이번 실기기 검사에서 재실행하지 않았습니다.
